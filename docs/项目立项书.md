# Intent2Prompt 项目立项书

> 面向中文学生创新场景的「意图到提示词编译器」
> 适用：挑战杯 / 大学生创新创业训练计划（大创）/ 社团项目 / 科研训练

---

## 一、项目名称与一句话定义

**Intent2Prompt** —— 把用户一句很短的中文意图，自动编译成结构化、高质量、可复制的 AI Prompt，并通过闭环质量评估保证可用性。

一句话：**让不会写 Prompt 的人，也能用一句话驱动 AI 产出专业级成果。**

---

## 二、项目背景与痛点

大模型已广泛进入校园，但**表达门槛**仍是最大障碍：

1. **用户只会说意图**：`帮我写挑战杯计划书`、`帮我做社团招新文案`，一句话就结束了。
2. **缺少结构化**：没有角色、约束、输出格式，AI 产出泛泛、跑偏、不可直接使用。
3. **不知道缺什么**：用户不知道一个好 Prompt 需要哪些信息，更不会主动补充。
4. **无法复用**：每次都从零开始，好用的 Prompt 无法沉淀成资产。

现有工具多为「Prompt 美化器」——只在文字上润色，**没有解决"信息缺失"和"质量可控"两个根本问题**。

---

## 三、解决方案与创新点

Intent2Prompt 的核心是 **「意图解析 → 缺失信息检测 → 结构化编译 → 质量评估」的闭环**，而非单点美化。

### 三大创新点

| 创新点 | 说明 | 区别于现有工具 |
| --- | --- | --- |
| **意图编译器**（Intent Compiler） | 把短意图当作"源代码"，编译成结构化 Prompt | 现有工具只做文字润色 |
| **缺失信息检测** | 按任务类型自动查出"还缺哪些关键信息"并主动追问（≤3 条） | 现有工具不追问、不补全 |
| **质量评估闭环** | 对生成的 Prompt 打分（100 分 / 7 维度）并给改进建议 | 现有工具产出不可量化、不可控 |

### 闭环示意

```
短意图 → 意图解析 → 缺失检测 → 追问 → 结构化构建 → 三版本编译 → 质量评估 → 可复用资产
                                                                          ↓
                                                                     改进建议回流
```

---

## 四、系统架构（八大模块）

| 模块 | 输入 | 输出 | 实现方式 |
| --- | --- | --- | --- |
| Intent Analyzer 意图解析器 | 短意图文本 | `IntentAnalysis`（任务类型/目标/场景/已知信息） | 规则为主，LLM 兜底 |
| Missing Info Detector 缺失信息检测器 | 意图 + 任务类型 | `MissingField[]`（缺失字段/优先级） | 规则（按任务类型查表） |
| Clarifying Question Generator 追问生成器 | 缺失字段 | ≤3 条追问（带候选选项） | 规则模板 |
| Prompt Schema Builder 结构构建器 | 意图 + 追问答案 | `PromptSchema`（角色/任务/约束/输出格式…） | 规则 + 模板填充 |
| Prompt Compiler 编译器 | `PromptSchema` | 简洁版 / 专家版 / 比赛·项目版 | 纯函数渲染 |
| Prompt Evaluator 质量评估器 | `PromptSchema` | 100 分评分 + 强弱项 + 建议 | 规则评分 |
| Template Library 模板库 | 任务类型 | 推荐角色/格式/约束/标准 | 纯数据 |
| History & Asset Manager 资产管理 | 历史会话 | 收藏 / 复用 Prompt | 本地存储 |

## 五、关键技术方案

1. **规则优先、LLM 兜底**：MVP 全程规则化（`classifyIntent` / `detectMissing` / `evaluatePrompt`），无需 API Key 即可演示，保证可复现、可演示；后续接入 `llmClient` 仅在低置信度时增强，不改变对外契约。
2. **任务分类体系**：11 类（项目策划 / 社团运营 / 写作 / 学术 / 编程 / 数据分析 / 调查问卷 / 学习辅导 / PPT演示 / 商业计划 / 其他），每类配独立模板与缺失字段规则。
3. **结构化 Prompt Schema**：统一的 `role / task / context / input / constraints / outputFormat / qualityCriteria / examples / clarifyingQuestions / assumptions / safetyNotes` 字段，作为编译前的中间表示。
4. **三种编译模式**：简洁版（日常）、专家版（高质量）、比赛·项目版（正式书面，章节齐全），一套 Schema 多形态输出。
5. **7 维度 100 分评估**：任务明确度 / 背景完整度 / 输出格式清晰度 / 约束合理性 / 可执行性 / 幻觉风险控制 / 中文表达质量，自动产出改进建议。

## 六、应用场景

- **创新竞赛**：挑战杯、大创项目计划书、商业计划书一键生成高质量起草 Prompt。
- **社团运营**：招新文案、活动策划、推文，按平台与人群精准生成。
- **学术科研**：论文总结、文献综述、问卷设计，降低科研训练的表达门槛。
- **课程学习**：复习提纲、知识点讲解、习题解析。
- **个人生产力**：把模糊需求编译成可执行的 AI 任务。

---

## 七、预期成果（MVP）

1. 可本地运行的 Web 应用（Next.js），首页输入一句中文意图即可走完整闭环。
2. 触达 11 类任务的场景模板库与缺失信息规则库。
3. 三版本 Prompt 编译 + 100 分质量评估。
4. 10 条中文测试样例与规则化单元验证。
5. Mock 模式：无 API Key 也能完整演示。

---

## 八、可行性分析

- **技术可行性**：核心链路已用 TypeScript 规则实现（`lib/` 下可运行函数），不依赖外部模型即可跑通；技术栈为校园团队熟悉的 Next.js。
- **成本可行性**：MVP 全规则化、零 API 成本；后续增强 LLM 仅在必要环节按需调用。
- **演示可行性**：闭环完整、可量化评分，适合答辩 / 路演现场展示。

---

## 九、项目亮点总结（一句话答辩版）

> Intent2Prompt 把"写 Prompt"这件依赖经验的事，工程化为一个 **可解析、可检测、可编译、可评估** 的流水线：用一句话意图，编译出三种专业 Prompt，并用 100 分量化保证它真的好用。

## 十、后续规划（MVP 稳定后再评估，不在首版范围）

> 严格遵循 `agent.md`：以下为稳定后的演进方向，**首版不做**。

- 接入真实 LLM（OpenAI / Claude）做低置信度增强与语义级评分。
- 提示词资产库与分享。
- 更多垂直场景模板（赛事专项、学科专项）。
- 团队协作 / 多端等。

**首版聚焦**：可运行、可演示、可复制的 MVP，证明"短意图 → 高质量结构化 Prompt"这一核心命题。
